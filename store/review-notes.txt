Remote AI Chat is a client for an open-source daemon that the user installs on
their own computer. There is no backend of ours and no account system. The app
connects over the user's own network to that daemon, which drives a
command-line coding agent the user has already installed and signed into.

Because of that, the app cannot be exercised end to end without a computer
running the daemon, and we cannot ship one with the app.

If you would like to drive it yourself, we will put a demo daemon online at a
public address for the duration of the review and send you a pairing link you
can open on the test device. Ask in Resolution Center and we will reply the
same day, within hours during European working time.

Everything the app does is also readable in the open source: the phone client,
the daemon, and the wire protocol between them are all in the public
repository linked at the bottom of this note.

Notes on specific items:

- Camera: used once, to scan the pairing QR code the daemon prints. Nothing is
  photographed or stored.
- Local network: the app connects directly to the user's own computer by IP
  address. It contacts no other host.
- App Transport Security: the connection is a WebSocket to a private address on
  the user's own network. There is no public hostname, so there is no
  certificate to obtain; the traffic never leaves the user's network, which on
  a tailnet is already encrypted at the network layer.
- Face ID: optional, for locking the app and for confirming a destructive
  command.
- The app collects no data at all — no analytics SDK, no crash reporting, no
  identifiers, and no server of ours to send them to.

Source code, daemon install instructions and the full wire protocol are public:
https://github.com/yakubilik/remote-ai-chat
